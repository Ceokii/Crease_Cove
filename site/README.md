# Crease Cove — локальный прототип сайта

Прототип работает **только на вашем компьютере** и показывает **тестовые данные**. Он не публикуется в интернете и ничего не стоит.

Основание: техническое задание [`docs/Crease_Cove_Technical_Specification.md`](../docs/Crease_Cove_Technical_Specification.md) (версия 1.1, утверждена 18.10.2026).

Текущее состояние: **шаг 1.1 — каркас сайта**. Готовы общий макет, два языка, баннер тестовых данных и все служебные страницы-заглушки. Каталог, страницы ассетов, 3D-превью и поиск появятся на следующих шагах (см. [`docs/dev/progress.md`](../docs/dev/progress.md)).

## 1. Установка на Windows 11 (один раз)

1. **Node.js 24 LTS.** Скачайте установщик Windows (`.msi`) на [nodejs.org/download](https://nodejs.org/en/download) и установите с настройками по умолчанию. Галочку «Tools for Native Modules» ставить не нужно.
2. **Git для Windows.** Скачайте с [git-scm.com/downloads/win](https://git-scm.com/downloads/win) и установите с настройками по умолчанию.

   Вместо шагов 1–2 можно выполнить в терминале встроенный менеджер программ Windows:

   ```
   winget install OpenJS.NodeJS.LTS
   winget install Git.Git
   ```

3. Откройте **новое** окно «Командной строки»: нажмите `Win + R`, введите `cmd`, нажмите Enter. Проверьте:

   ```
   node --version
   git --version
   ```

   Первая команда должна показать `v24.…`, вторая — номер версии Git.

4. Скачайте проект в короткую папку без пробелов и кириллицы, например `C:\Projects`:

   ```
   mkdir C:\Projects
   cd C:\Projects
   git clone https://github.com/Ceokii/Crease_Cove.git
   cd Crease_Cove
   git checkout claude/project-research-001-en4i8m
   cd site
   npm ci
   ```

   `npm ci` скачивает библиотеки проекта (несколько сотен мегабайт) в папку `node_modules`. Оплата и регистрация не нужны. В конце установки автоматически отключается сбор анонимной статистики Astro.

## 2. Запуск

В папке `site` выполните:

```
npm run demo
```

Команда соберёт сайт и запустит его. Откройте в браузере адрес **http://localhost:4321**. Остановить сайт: `Ctrl + C` в окне командной строки.

Получить свежие изменения позже:

```
cd C:\Projects\Crease_Cove
git pull
cd site
npm ci
npm run demo
```

## 3. Все команды

Выполняются в папке `site`.

| Команда | Что делает |
|---|---|
| `npm run demo` | Собирает сайт и показывает его на http://localhost:4321. **Основная команда для просмотра** |
| `npm run dev` | Режим разработки: изменения в файлах видны сразу после сохранения |
| `npm run build` | Собирает сайт в папку `dist` |
| `npm run preview` | Показывает уже собранный сайт |
| `npm run check` | Проверка кода и шаблонов (`astro check`) |
| `npm run links` | Проверка всех ссылок в собранном сайте |
| `npm run test:e2e` | Автоматические сценарии в браузере (Playwright) |
| `npm run check-all` | Все проверки подряд. Запускает исполнитель перед каждой сдачей работы; вам — по желанию |

Чтобы запустить `test:e2e` или `check-all` у себя, один раз скачайте браузер для тестов: `npx playwright install chromium` (бесплатно).

## 4. Частые проблемы

| Признак | Решение |
|---|---|
| «node не является внутренней или внешней командой» | Node.js не установлен или окно открыто до установки. Установите и откройте новое окно |
| PowerShell пишет, что выполнение сценариев отключено (`npm.ps1`) | Используйте «Командную строку» (`cmd`). Менять настройки безопасности Windows не нужно |
| Сайт открылся не на 4321, а на другом порту (например, 4322) | Сайт уже запущен в другом окне. Закройте лишнее окно (`Ctrl + C`) или откройте адрес, который показан в терминале |
| Брандмауэр Windows спрашивает разрешение | Не должен: сайт слушает только `localhost`. Если спросил — нажмите «Отмена» и сообщите исполнителю |

## 5. Правила прототипа

- Только `localhost`. Флаг `--host` и публикация сайта запрещены (ТЗ, SEC-02).
- Никаких внешних запросов со страниц: шрифты системные, аналитики нет (ТЗ, SEC-03). Это проверяет автотест.
- Все ассеты — тестовые и помечены «ТЕСТ» / «TEST» (ТЗ, раздел 8.5).
- Новые библиотеки — только с согласия владельца (ТЗ, раздел 4.7).

## 6. Как устроен код

Кратко: страницы лежат в `src/pages/[lang]/`, общий макет — в `src/layouts/BaseLayout.astro`, тексты интерфейса — в `src/i18n/ru.json` и `src/i18n/en.json`, все цвета и размеры — в `src/styles/tokens.css`.

Подробно: [`docs/dev/architecture.md`](../docs/dev/architecture.md).
