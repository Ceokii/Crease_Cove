# CLAUDE.md — правила для работы с репозиторием Crease Cove

Этот файл читает Claude Code в начале каждой сессии. Здесь — постоянные правила проекта. Подробности — в документах, на которые даны ссылки.

## Проект

Crease Cove — бесплатная библиотека 3D-ассетов (Blender + ИИ). Сейчас идёт **этап 1: локальный прототип сайта на тестовых данных**.

- ТЗ (главный документ, утверждено 18.10.2026): `docs/Crease_Cove_Technical_Specification.md`
- Исследование: `docs/Crease_Cove_Project_Research.md`
- Технические заметки: `docs/dev/` (устройство, журнал решений, ресурсы, ход работ)
- Код сайта: `site/` (инструкция: `site/README.md`)

## Общение с владельцем

- Отвечать на русском, структурированно, отделяя факты от предположений.
- Владелец не профессиональный веб-разработчик: объяснять простыми словами.
- Сайт делается **поэтапно**, строго по критериям и дизайнерским решениям владельца. После каждого шага — отчёт и ожидание согласия на следующий (решение O1).

## Жёсткие ограничения (нарушать нельзя)

1. **Бюджет 0.** Никаких покупок, подписок, платных тарифов, регистраций, ввода платёжных данных без явного согласия владельца.
2. **Только локально.** Сервер на `localhost`. Не добавлять `--host`, `server.host`, деплой, публичные адреса.
3. **Только тестовые данные.** Каждая запись `isTest: true`; названия «ТЕСТ — » / «TEST — »; файлы `_TEST`. Никаких реальных или чужих ассетов.
4. **Никаких внешних запросов со страниц**: нет CDN, внешних шрифтов, аналитики, трекеров. Проверяется автотестом.
5. **Новые библиотеки — только с согласия владельца** (ТЗ, раздел 4.7). Список разрешённых — ТЗ, раздел 4.2, и `docs/dev/resources.md`.
6. **Дизайн определяет владелец.** Не придумывать фирменный стиль. Все цвета, шрифты и размеры — только через `site/src/styles/tokens.css`.
7. Ветку в `main` сливает только владелец.

## Команды (в папке `site/`)

| Команда | Назначение |
|---|---|
| `npm ci` | Установка зависимостей |
| `npm run dev` | Режим разработки |
| `npm run build` | Сборка в `dist/` |
| `npm run demo` | Сборка и просмотр на http://localhost:4321 |
| `npm run check-all` | Все проверки: `astro check`, сборка, ссылки, Playwright. **Обязательно перед каждым коммитом с кодом** |

В облачной среде Claude Code:

- Node.js 24: временная копия может лежать в папке scratchpad; системный Node.js 22.22 тоже подходит (`engines: >=22.22.0`).
- Playwright: `PW_CHROMIUM_EXECUTABLE=/opt/pw-browsers/chromium npm run test:e2e` (не запускать `playwright install`).
- Astro 7 распознаёт ИИ-агента и уводит `astro dev`/`astro preview` в фон. Для разового сервера на переднем плане добавлять `--ignore-lock`; фоновые серверы останавливать `npx astro preview stop` / `npx astro dev stop`.

## Правила кода

- TypeScript в строгом режиме; `npm run check` без ошибок.
- Тексты интерфейса только в `site/src/i18n/ru.json` и `en.json` (структуру задаёт `ru.json`). Ссылки — через `localizedPath()`.
- Новая страница: файл в `site/src/pages/[lang]/`, тексты в обоих словарях, путь в `site/tests/routes.ts` (см. `docs/dev/architecture.md`, раздел 4).
- Комментарии в коде — на русском, кратко, со ссылкой на пункт ТЗ, если код реализует требование.
- Коммиты небольшие, сообщения на английском в повелительном наклонении.

## Документация

При каждом изменении кода в том же коммите обновлять затронутые файлы `docs/dev/`:

- `progress.md` — статус шага;
- `decisions.md` — новое решение (не удалять старые);
- `resources.md` — изменение зависимостей;
- `architecture.md` — изменение устройства.
