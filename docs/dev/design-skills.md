# Скиллы для дизайна сайта: оценка, выбор, установка

Заметка для владельца проекта. Проверено 19.10.2026: репозитории скачаны и просмотрены, лицензии проверены по файлам LICENSE. Источники в конце.

## 1. Что такое скилл, с нуля

**Скилл** (Skill) — это папка с инструкциями для Claude. Главный файл `SKILL.md` — обычный текст: правила, приёмы, примеры, иногда справочники (палитры, шрифтовые пары) и небольшие скрипты.

Как это работает:

1. Вы включаете скилл в настройках Claude или кладёте его в проект Claude Code.
2. Claude видит только **название и краткое описание** каждого скилла.
3. Когда задача подходит под описание (например, «сделай дизайн страницы»), Claude сам открывает скилл и работает по его правилам.

Скилл не рисует сам и не является программой. Это **опыт хорошего дизайнера, записанный в виде правил**, который Claude применяет к вашей задаче. Поэтому хороший скилл заметно меняет результат: меньше шаблонных решений «как у всех ИИ-сайтов», продуманнее шрифты, цвета, отступы и анимации.

## 2. Оценка идеи

Идея хорошая, но с тремя оговорками.

1. **Меньше — лучше.** Скиллы — это наборы правил. Если включить сразу пять разных «вкусов», они начнут противоречить друг другу, и дизайн станет хуже. Рекомендую 2–3 проверенных скилла, которые дополняют друг друга: общий стиль, анимации, проверка качества.
2. **Скиллы в claude.ai доступны только на платных планах** (Pro, Max, Team, Enterprise) и требуют включённой настройки «Code execution and file creation». На бесплатном плане загрузить скилл нельзя. Обходной путь — вставить текст `SKILL.md` в чат как инструкцию (раздел 5).
3. **Работают ли скиллы внутри Claude Design — официально не подтверждено.** Claude Design теперь создаётся из обычного чата Claude, поэтому включённые скиллы, скорее всего, применяются. Но в справке Anthropic это прямо не написано. Как проверить — раздел 4, шаг 5.

Главная польза скиллов будет **в двух местах**:

- в Claude Design — при создании макетов (ваша часть);
- у исполнителя в Claude Code — при вёрстке по макету и при создании анимаций (моя часть). Здесь скиллы работают точно: Claude Code — их основная среда. Установка в репозиторий бесплатна и делается после вашего согласия.

## 3. Рекомендуемые скиллы

Все бесплатные, с открытыми лицензиями.

| № | Скилл | Автор | Лицензия | Что делает | Где использовать |
|---|---|---|---|---|---|
| 1 | **frontend-design** | Anthropic (официальный) | Apache-2.0 | Общее направление дизайна. Сначала понять предмет и аудиторию, потом выбрать стиль, шрифты, сетку. Борется с типовыми «ИИ-клише» (одинаковые карточки, модные градиенты). Требует доступности, адаптивности, сдержанной анимации | Claude Design и Claude Code |
| 2 | **design-taste-frontend** (Taste Skill v2) | Leonxlnx | MIT | Самый «выразительный». Арт-дирекция, выведенная из анализа 247 сайтов-победителей Awwwards и One Page Love. Библиотека направлений, палитр, шрифтов, композиций первого экрана, анимаций. Проверяет страницу по скриншотам и исправляет | Claude Design и Claude Code |
| 3 | **emil-design-eng** | Эмиль Ковальски (дизайн-инженер, автор известных UI-библиотек) | MIT | Тонкая полировка интерфейса: какие элементы анимировать, а какие нет, длительность и плавность движений, отклик на нажатие и наведение, переходы | Claude Design и Claude Code |

Дополнительно, **только для исполнителя в Claude Code** (ставятся в репозиторий после вашего согласия):

| Скилл | Автор | Лицензия | Зачем |
|---|---|---|---|
| `animate`, `review-animations`, `improve-animations` | Эмиль Ковальски | MIT | Создание анимаций и их проверка по строгим правилам |
| `design-system` из UI/UX Pro Max | nextlevelbuilder | MIT | Справочник стилей, палитр и шрифтовых пар; помогает перевести ваш макет в систему дизайн-токенов. Для claude.ai не подходит: больше 200 файлов |
| GSAP Skills | GreenSock (официальный) | MIT | Сложные анимации при прокрутке. **Только если вы разрешите библиотеку GSAP** — это новая зависимость (ТЗ, раздел 4.7). Сама библиотека GSAP бесплатна полностью |

**Что не советую сейчас:** ставить много похожих скиллов одновременно; скиллы, которые подключают платные сервисы или генерацию изображений через внешние API.

### Что важно знать о Taste Skill

Это самый сильный скилл для выразительности, но у него жёсткие собственные правила. Например, он требует настоящих фотографий на странице, обязательный слой анимаций и подключает шрифты и библиотеки анимации из интернета. Для макета это нормально. Но в нашем сайте действуют правила ТЗ: изображения пока только тестовые заглушки, шрифты встраиваются файлами, внешних запросов нет. Поэтому в запросе к Claude Design эти ограничения прописаны явно, а при вёрстке исполнитель переводит макет на локальные ресурсы.

## 4. Установка в claude.ai (для Claude Design)

Готовые архивы лежат в проекте, в папке `design-skills/` (собраны из официальных репозиториев, без изменений, с файлами лицензий):

| Файл | Размер | Исходный коммит |
|---|---|---|
| `frontend-design.zip` | 8 КБ | `anthropics/skills@dbd4588` |
| `design-taste-frontend.zip` | 750 КБ, 39 файлов | `Leonxlnx/taste-skill@a9c73c3` |
| `emil-design-eng.zip` | 11 КБ | `emilkowalski/skills@2d22863` |

Шаги:

1. Откройте Claude в браузере или приложении → **Settings** (Настройки) → **Capabilities** (Возможности).
2. Включите **Code execution and file creation**. Без этого раздел скиллов не работает.
3. Ниже найдите раздел **Skills**. Если там уже есть **frontend-design** среди встроенных примеров Anthropic, просто включите его переключателем; загружать архив не нужно.
4. Нажмите **Upload skill** и по очереди загрузите `design-taste-frontend.zip` и `emil-design-eng.zip` (и `frontend-design.zip`, если встроенного нет). Проверьте, что все три включены.
5. **Проверка.** Откройте новый чат и спросите: «Какие скиллы у тебя сейчас доступны?» Потом начните дизайн (шаблон Design во вкладке Artifacts или просьба в чате) и в начале запроса напишите: «Используй скиллы frontend-design, design-taste-frontend и emil-design-eng». Если Claude упоминает, что открыл скилл, — всё работает.

Если что-то не загружается: имя папки внутри архива должно совпадать с названием скилла (в наших архивах это соблюдено), а архив не должен превышать лимит размера.

## 5. Если план бесплатный

Загрузить скиллы нельзя, но можно передать их правила вручную:

1. Откройте `SKILL.md` нужного скилла на GitHub (ссылки ниже).
2. Скопируйте текст и вставьте в начало чата Claude Design с фразой: «Следуй этим правилам при создании дизайна».
3. Лучше всего подходят короткие `frontend-design` и `emil-design-eng`. У Taste Skill много дополнительных файлов, поэтому вручную он работает только частично.

### Как передавать референсы в Claude Design

1. Сделайте скриншот понравившегося места: в Windows 11 — `Win + Shift + S`, затем выделить область.
2. Прикрепите скриншоты к сообщению в Claude Design.
3. **К каждому скриншоту напишите, что именно нравится**: «крупный заголовок и много воздуха», «сетка карточек», «тёмный фон с яркими акцентами», «плавное появление блоков». Без пояснений Claude может скопировать не то.
4. Референс — это источник вдохновения, а не образец для копирования. Не просите повторить чужой сайт один в один: это нарушает права авторов и делает сайт неузнаваемым.

## 7. Как анимации попадут в сайт

- **Без новых библиотек (по умолчанию):** плавные переходы между страницами (View Transitions, встроены в Astro и браузеры), анимации при наведении и нажатии, появление блоков при прокрутке на CSS. Этого достаточно для выразительного и быстрого сайта.
- **С библиотекой GSAP (по отдельному согласию):** сложные сцены при прокрутке, закрепление блоков, анимация текста по буквам. GSAP бесплатен полностью, но это новая зависимость.
- Во всех случаях учитывается системная настройка «уменьшить движение»: людям, которым анимации мешают, сайт показывается без них.
