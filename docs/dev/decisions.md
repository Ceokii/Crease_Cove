# Журнал решений

Все решения, влияющие на устройство проекта: кто принял, когда и почему. Новое решение добавляется в конец таблицы и не удаляет старые. Если решение отменено, добавляется новая строка со ссылкой на отменённую.

Решения владельца имеют приоритет. Технические решения исполнителя принимаются в рамках утверждённого ТЗ и могут быть пересмотрены владельцем.
