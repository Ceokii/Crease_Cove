## Шаг 1.1 — подробности

Сделано:

- Проект Astro 7.4.0 в `site/`, TypeScript в строгом режиме, статическая сборка.
- Сервер только на `localhost:4321`; панель разработчика и телеметрия Astro отключены.
- Два языка (`/ru/`, `/en/`), корень `/` ведёт на `/ru/`, переключатель языка на каждой странице.
- Общий макет: баннер тестовых данных, шапка, подвал, ссылка «Перейти к содержимому».
- Все статические страницы из раздела 9 ТЗ как заглушки (каталог, поиск, лицензия, стандарт качества, о проекте, три правовые страницы), страница 404.
- Дизайн-токены в `src/styles/tokens.css`; оформление нейтральное до решений владельца.
- Автоматические проверки: `astro check`, сборка, `linkinator`, 25 сценариев Playwright.
- Файлы `.gitattributes` и `.editorconfig` для одинаковой работы на Windows и Linux.
- Технические заметки: `docs/dev/` и `CLAUDE.md`.

Не входит в шаг 1.1 (будет позже): данные, каталог, страницы ассетов, 3D-превью, поиск, тексты служебных страниц.

Снимки экрана шага 1.1 (сделаны автоматически в среде исполнителя, Chromium): [`screenshots/step-1.1/`](screenshots/step-1.1/).
